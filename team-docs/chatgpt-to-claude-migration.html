01

Why we're switching & what to expect

Dispenza is standardizing on Anthropic's Claude (chat) and Claude Code (CLI) for AI work. Claude has stronger long-context reasoning, better tool use for our marketing automation, and Claude Code lets engineers and analysts work directly against project files without copy-pasting.

What you had in ChatGPT

  • Conversations & saved chats
  • Custom GPTs (instructions + knowledge files)
  • Projects (folders of related chats)
  • Memory (auto-recall across chats)
  • GPT Store, Code Interpreter, Canvas

What you'll have in Claude

  • Conversations & chat history
  • Projects (instructions + knowledge files)
  • Same — Claude Projects replace both
  • Memory (manual file-based, more controllable)
  • Artifacts, Tool Use, Claude Code (CLI)
Bottom line: Most things you used in ChatGPT have a direct equivalent in Claude. The export we'll do in Phase 1 captures everything you need, and Phases 4–6 walk through rebuilding it.
02

Phase 1 — Export your ChatGPT data

OpenAI lets you download a complete archive of your ChatGPT data — every conversation, custom GPT, and uploaded file. The download arrives via email within 24 hours (usually under an hour).

  1. Go to chat.openai.com and sign in with your work account.
  2. Click your profile picture (bottom-left) → Settings.
  3. Open the Data Controls tab.
  4. Find Export data and click Export. Confirm by clicking Confirm export in the popup.
  5. Wait for the email from OpenAI titled "ChatGPT — Your data export is ready". The download link is valid for 24 hours.
  6. Click the link, download the .zip file, and save it to your computer (suggested: ~/Documents/chatgpt-export-2026/).
If you have a ChatGPT Team/Enterprise account: Your workspace admin may need to approve the export or run it on your behalf. Ping the admin in #it-help if "Export data" is greyed out.

Phase 2 — Organize what you exported

Don't try to migrate everything. Most chats are throwaway. Sort what's worth bringing over before you start rebuilding.

  1. Unzip the archive into a clearly named folder (e.g., chatgpt-export-2026/).
  2. Open chat.html in your browser. This gives you a scrollable view of every conversation.
  3. Triage your chats into three buckets:
    • Active — ongoing work you'll continue (client strategy, in-progress copy, code projects). Bring these over.
    • Reference — past work you may want to look up later (campaign briefs, research, prompts that worked). Archive locally; don't migrate.
    • Trash — quick lookups, one-off questions. Ignore.
  4. For each Custom GPT you built, copy its system instructions and any uploaded knowledge files into a folder named after the GPT (e.g., custom-gpts/AlpineIQ-Copy-Coach/). You'll rebuild these as Claude Projects in Phase 4.
  5. For each ChatGPT Project, note the project's name, instructions, and which chats it contained.
Time-saving tip: Don't try to convert every old chat into a perfect document. The goal is to capture what you want to keep working on, not preserve a museum.

Phase 3 — Set up your Claude account

Claude lives at claude.ai. Use your Dispenza work email for the account.

  1. Go to claude.ai/signup.
  2. Sign up with your @dispenza.com email (or whatever your work email is).
  3. Verify your email and complete the onboarding prompts.
  4. If we have a Claude Team workspace, accept the invite from your admin (check email for "You've been invited to a Claude Team workspace"). Otherwise, your admin will upgrade your account to the team plan once you sign up.
  5. Open Settings → Profile and add a short profile description (your role + main projects). Claude uses this to tailor responses.

Phase 4 — Rebuild Projects & Custom GPTs in Claude

Claude Projects = ChatGPT Projects + Custom GPTs combined. Each project holds custom instructions, knowledge files, and a dedicated chat history.

Create a new Project

  1. In Claude, click Projects in the left sidebar → Create Project.
  2. Name it after the client or workstream (e.g., "Joyleaf — Local SEO" or "AlpineIQ Copy Coach").
  3. Paste your old ChatGPT system instructions (or Custom GPT instructions) into Custom Instructions. Edit for clarity if needed.
  4. Upload the project's knowledge files (PDFs, Docs, CSVs) into Project Knowledge. Limit ~200K tokens of context.
  5. Start a new chat inside the project. Test that Claude is using the instructions correctly with a few real-world prompts.

Phase 5 — (Devs & analysts) Install Claude Code

Claude Code is Anthropic's CLI — Claude operating directly inside your terminal and project folders. Skip this section if you don't write code or work with local files.

Install

  1. Install Node.js 18+ if you don't already have it: nodejs.org (download the LTS).
  2. Open Terminal (Mac) or PowerShell (Windows) and run: 
    npm install -g @anthropic-ai/claude-code
  3. Navigate to a project folder and start Claude Code: 
    cd ~/projects/my-project
claude
  4. The first time, Claude Code will prompt you to authenticate. Choose "Log in with Claude.ai" and approve in your browser.
  5. Once authenticated, just type your request in plain English. Claude reads/writes files in that folder.
First thing to try: in any existing project folder, run claude, then type /init. Claude reads the codebase and writes a CLAUDE.md file documenting it. That file becomes context for every future session in that folder.

Useful slash commands

CommandWhat it does
/initGenerate a project context file (CLAUDE.md)
/helpFull list of commands
/clearReset the conversation
/configChange theme, model, settings
/reviewReview a pull request

Phase 6 — Bring active threads into Claude

For ongoing chats you flagged as "Active" in Phase 2, you have three options. Pick one per thread — don't try to import full chat histories verbatim.

Option A — Summary handoff (recommended for most chats)

  1. In ChatGPT, ask the chat: "Write a complete handoff brief for a new AI assistant: what we're working on, decisions made, open questions, and the next 3 steps."
  2. Copy the result.
  3. Paste it as the first message in a new Claude conversation (inside the relevant Claude Project).
  4. Tell Claude: "This is the context. Pick up where ChatGPT left off."

Option B — Full transcript paste (for shorter critical chats)

  1. Open the chat in chat.html from your export.
  2. Copy the full conversation text.
  3. Paste into a new Claude chat with: "Below is a full ChatGPT transcript. Read it, then continue from the last message."

Option C — File upload (for long, document-heavy chats)

  1. Save the conversation to a .txt or .md file.
  2. Upload it as a Project Knowledge file in the matching Claude Project.
  3. Reference it in chats: "Per the migration brief in our project knowledge…"
Don't: upload conversations.json directly. It's not human-readable and wastes context window. Always extract the chat you actually need first.

Final migration checklist

Print this or copy it into your task manager. You're done when every box is checked.

  • Exported my full ChatGPT archive and saved it locally
  • Triaged old chats into Active / Reference / Trash
  • Saved Custom GPT instructions + knowledge files for each one I'll rebuild
  • Created a Claude.ai account with my Dispenza work email
  • Joined the Dispenza team workspace (or confirmed plan with manager)
  • Created a Claude Project for each active client / workstream
  • Pasted Custom GPT instructions into the matching Project
  • Uploaded knowledge files into Project Knowledge
  • (Devs only) Installed Claude Code and ran /init on at least one project
  • Migrated my top 3–5 active threads using Option A, B, or C
  • Tested a real client task end-to-end in Claude before deleting ChatGPT export
  • Bookmarked claude.ai and removed ChatGPT from my browser shortcuts
