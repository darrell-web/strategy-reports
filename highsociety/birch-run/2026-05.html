Why this plan will hit its KPIs

Birch Run is the chain's cross-platform review leader on Weedmaps (489 reviews / 4.9★ — 2.5× Big Rapids' 192) and operates in a uniquely-positioned market (I-75 corridor + Birch Run Premium Outlets adjacent + Frankenmuth tourism within 15 minutes). The May plan turns three currently-unleveraged signals into search-engine-readable copy + recovers a removed Facebook profile.

Proof point #1 · Cross-platform review leadership

Birch Run carries 758 Google reviews / 4.8★ + 489 Weedmaps reviews / 4.9★ — earned in ~32 months (Sept 2023 opening). Effective velocity: ~24/mo Google + ~15/mo Weedmaps. Only Charlotte (~123/mo Google) and East Lansing (~49/mo) outpace Birch Run on per-month velocity. The review machine is robust.

Proof point #2 · Outlet adjacency = unclaimed traffic moat

Birch Run Premium Outlets directly adjacent (~50+ retailers, ~2-3M visitors/year). Emagine Birch Run movie theater immediately south. I-75 Exit 136 visible on the map. The current GBP description references zero of these. "Outlet" appears in the business name but the adjacency context isn't surfaced for searchers.

Proof point #3 · Frankenmuth tourist proximity (~3M annual visitors)

Frankenmuth ("Michigan's Little Bavaria") is ~15 min north on I-75 — draws ~3M tourists/year. Out-of-area tourists with high-cannabis intent + low-competitive-density (in-state border zone) = high-conversion traffic. Description: 0 references. Major unclaimed trust + traffic signal.
